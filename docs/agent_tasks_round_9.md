# Agent Tasks Round 9

Round 9 introduces the recognition modeling layer before any real PDF/DWG/DXF parser adapter is added.

Round 8 provided:

```text
install_task + install_dependency
  -> workflow_plan
  -> workflow_step
  -> workflow_issue
```

Round 9 should make this work:

```text
source document
  -> drawing page
  -> drawing primitive
  -> recognition candidate
  -> object hypothesis
  -> accepted hypothesis
  -> normalized object import boundary / ObjectStore
```

## Round Goal

Implement the first auditable recognition evidence layer.

The output of Round 9 is not a real PDF parser, DWG parser, OCR engine, computer vision model, LLM classifier, API, UI, or production inference service. It is a durable model for storing:

- source documents and page/layout context
- low-level drawing primitives extracted by a future parser
- recognition candidates generated by a future model/rule/parser
- object hypotheses assembled from candidates and primitives
- an explicit acceptance boundary that can create final `cad_object` rows through `ObjectStore`

Round 9 should answer questions like:

```text
Which source document and page did this object come from?
Which primitives support a candidate recognition result?
Which candidates support an object hypothesis?
Which hypothesis was accepted into cad_object?
Can rejected or superseded recognition results remain auditable?
```

## Agent C: Hypothesis Acceptance Service

### Objective

Accept object hypotheses into final objects through `ObjectStore`.

### Allowed Files

- `dwg_rec_system/services/`
- `dwg_rec_system/repositories.py`
- `tests/`
- `docs/` only for clarifying behavior

### Disallowed Changes

- Do not bypass `ObjectStore`.
- Do not accept rejected hypotheses.
- Do not run quantity/budget/installation/workflow generation.
- Do not use LLMs or external dependencies.

### Required Behavior

Suggested API:

```python
class HypothesisAcceptanceService:
    def accept(
        self,
        hypothesis_id: str,
        accepted_by: str | None = None,
        acceptance_method: str = "manual",
    ) -> dict: ...
```

Acceptance should:

- load the hypothesis
- reject acceptance if hypothesis is missing or rejected
- return existing mapping if already accepted
- create an `ObjectInput` from hypothesis class, subtype, geometry, attributes, and source metadata
- call `ObjectStore.create_object`
- insert `hypothesis_to_object`
- mark hypothesis `accepted`
- mark linked candidates `accepted` when they are still pending
- return `hypothesis_id` and `object_id`

### Required Tests

Add tests for:

- pending hypothesis accepts into `cad_object`
- accepted object stores geometry and attributes from hypothesis
- second acceptance returns existing object mapping
- rejected hypothesis cannot be accepted
- linked pending candidates become accepted
- ObjectStore identity uses deterministic source file/local id
